# Blood Bank Management System

A Java Swing desktop application built as a team project for our Java Lab course at Southeast University.

## Features
- Admin login
- Add donors (name, ID, age, blood group, contact)
- Add blood stock for all 8 blood groups
- Handle patient blood requests (checks stock first)
- View stock, donors, and requests

## How to run
1. Download all the .java files into one folder
2. Open a terminal in that folder
3. Compile: `javac *.java`
4. Run: `java Main`
