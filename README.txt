BLOOD BANK SWING GUI

Files:
1. BloodInventory.java
2. BloodRequest.java
3. Donor.java
4. BloodBankGUI.java

How to run:
1. Put all 4 files in the same folder.
2. Open terminal/command prompt in that folder.
3. Compile:
   javac *.java
4. Run:
   java BloodBankGUI

The GUI uses basic Java Swing components and keeps the original class structure.
